# JCE Cafe ☕

JCE Cafe is a simple MERN stack college cafe application.

## Technologies Used

- React.js
- Node.js
- Express.js
- MongoDB
- Mongoose

## Features

- User Registration
- User Login
- View Menu
- Add Food to Cart
- Remove Food from Cart
- View Total Price
- Place Order
- Logout

## How to Run

### Backend

```bash
cd server
node server.js
````

### Frontend

Open another terminal:

```bash
cd client
npm run dev
```

Open the application at:

[http://localhost:5173](http://localhost:5173)
